# Security policy

## Reporting a vulnerability

Please report security problems privately through GitHub's
[private vulnerability reporting](https://github.com/irashack/night-desk/security/advisories/new)
rather than a public issue. Include the affected version, how to reproduce the
problem and what an attacker could do with it.

You should get an acknowledgement within a week. Fixes ship in a new release, and
the advisory is published once one is available.

## Supported versions

Night Desk is pre-1.0: only the latest release receives security fixes.

## Scope

Of particular interest: anything that lets one reader see another reader's
paper, a key act beyond its capabilities, the gathering worker reach the
database or private network addresses it was not allowed, or webhook and push
deliveries reach unintended destinations.
